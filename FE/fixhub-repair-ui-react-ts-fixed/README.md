# FixHub — React + TypeScript UI

Frontend UI prototype for the computer repair appointment management system.

## Chức năng giao diện

UI bám theo tài liệu use case mẫu, gồm 25 chức năng:
1. Đăng ký
2. Đăng nhập
3. Đăng xuất
4. Chỉnh sửa thông tin
5. Xem dịch vụ
6. Đặt lịch
7. Quản lý lịch hẹn
8. Theo dõi sửa chữa
9. Duyệt báo giá
10. Thanh toán
11. Xem lịch sử sửa chữa
12. Đánh giá dịch vụ
13. Gửi yêu cầu bảo hành
14. Tiếp nhận thiết bị
15. Quản lý phiếu sửa chữa
16. Chẩn đoán và đề xuất sửa chữa
17. Tạo và gửi báo giá
18. Xử lý lịch hẹn
19. Thực hiện sửa chữa
20. Kiểm tra và hoàn thành
21. Quản lý nhân viên
22. Quản lý dịch vụ
23. Quản lý khách hàng
24. Quản lý phiếu sửa chữa
25. Xem báo cáo

## Chạy

```bash
npm install
npm run dev
```

Mở `http://localhost:5173`.

## Ghi chú

- Chưa kết nối backend/API/database.
- Dữ liệu đang là mock để tập trung vào UI/UX.
- Có thể chuyển từng action trong `App.tsx` thành API call sau này.
- UI có responsive mobile, dark/light theme, modal, toast, filter, search, progress, timeline, bảng dữ liệu và dashboard.
